# Documentar el README

1. Lee el proyecto: qué hace, cómo se instala y cómo se corre.
2. Escribe para alguien que llega por primera vez.
3. Secciones: qué es, requisitos, instalación, uso, cómo contribuir.
4. Comandos en bloques de código que se puedan copiar.
