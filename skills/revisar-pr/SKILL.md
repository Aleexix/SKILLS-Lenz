# Revisar un PR

1. Mira el diff contra la rama principal.
2. Busca errores de lógica, casos sin manejar y cambios que rompan a otros.
3. Ordena los hallazgos de más grave a menos, con archivo y línea.
4. Si no encuentras nada importante, dilo en una línea.
