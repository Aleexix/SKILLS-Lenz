# Revisar accesibilidad

1. Todo lo que se hace con el mouse debe poder hacerse con el teclado.
2. El foco se ve y sigue un orden lógico.
3. Los botones e íconos tienen un nombre accesible.
4. El texto tiene contraste suficiente con el fondo.
