# Escribir tests

1. Busca cómo se prueban hoy archivos parecidos y sigue ese estilo.
2. Cubre primero el caso normal, después los bordes (vacío, error, límites).
3. Una prueba por comportamiento, con un nombre que diga qué se espera.
4. Corre las pruebas y muestra el resultado real.
